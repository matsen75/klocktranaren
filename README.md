# ⏰ Klocktränaren

Ett webbspel för att lära sig klockan – både analog och digital. Gjort för Valter.

**Spela:** https://matsen75.github.io/klocktranaren/

## Innehåll

- **6 världar** som bygger på varandra: hela timmar → halvtimmar → kvartar → fem minuter → varje minut → dygnet runt (24-timmarsklocka)
- **Många övningstyper:** läsa analog klocka, ställa visarna själv (dra eller knappar), matcha digital och analog tid, skriva digital tid på knappsats, svenska uttryck ("fem i halv fyra"), tidsresor ("vad är klockan om en kvart?") och förmiddag/eftermiddag
- **Bossfajter** i slutet av varje värld – analoga och digitala bossar med hjärtan, tidsgräns och SUPERSLAG för snabba svar. Slutbossen Kronox byter från analog till digital form mitt i striden!
- **Belöningar:** stjärnor, mynt, nivåer och titlar, 20 medaljer, butik med figurer och klockutseenden
- **Snabbrunda** på 60 sekunder med rekord
- 🔊 Uppläsning av frågor (för den som inte läser så snabbt än) och hjälpsiffror för minuter
- Man skriver sitt namn och väljer figur första gången man spelar
- **Installera på telefonen:** Android/Chrome visar knappen ”📲 Installera på telefonen” på startsidan. På iPhone/iPad: öppna i Safari → Dela ⬆️ → ”Lägg till på hemskärmen”. Spelet fungerar sedan även utan nät.
- Framsteg sparas i webbläsaren.
- Föräldrar kan låsa upp alla världar genom att lägga till `#lasupp` i slutet av adressen (och låsa igen med `#laslas`).

## Teknik

Ren HTML, CSS och JavaScript – inga beroenden. Öppna via GitHub Pages eller kör en valfri lokal webbserver i mappen.
